# Pharmacy Management System (C++)

A console-based application built using **C++** fundamentals to manage a pharmacy's inventory, handle medicine registration, lookups, and billing operations.

## 🚀 Features
- **Add New Medicines:** Register medicine names, prices, and available stock.
- **Display Inventory:** Show a formatted list of all available medicines.
- **Search Functionality:** Instantly look up a specific medicine's price and stock status.
- **Billing & Sales:** Simulate a real checkout process, validating stock availability and auto-updating quantity upon transaction completion.

## 🛠️ Concepts Applied (ICPC Level 1)
- Advanced Arrays & Multi-arrays tracking.
- String handling & buffer clearing.
- Modular programming using discrete C++ Functions.
- Control flow structures & infinite loops validation.
